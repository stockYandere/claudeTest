# ClaudeTest

간단한 Hello World 안드로이드 앱입니다.

## APK 받기

1. 푸시하면 GitHub Actions의 **Build APK** 워크플로가 자동으로 실행됩니다. (Actions 탭에서 **Run workflow**로 직접 실행할 수도 있습니다.)
2. Actions 탭에서 완료된 실행을 열고, 아래쪽 **Artifacts**에서 `ClaudeTest-apk`를 내려받습니다.
3. 받은 zip 파일을 풀어 나온 `app-debug.apk`를 폰에 설치합니다. (출처를 알 수 없는 앱 설치 허용이 필요할 수 있습니다.)
